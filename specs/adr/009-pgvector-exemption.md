# ADR-009: 竞赛阶段豁免 pgvector 向量检索

## 状态
已采纳 (2026-10-23)

## 背景
跨源冲突研判中的主体名称匹配需要语义检索能力，阿里云 PG 16 已提供 pgvector 0.8.0.2 扩展。

## 决策
竞赛阶段豁免 pgvector，降级为规则引擎 + 模糊匹配（编辑距离/正则）+ LLM fallback。

## 否决方案
- **生产阶段启用 pgvector 语义检索**：时间紧张，名称匹配可用规则 + LLM 替代

## 理由
- 竞赛时间紧张，向量检索集成和调优成本高
- 主体名称冲突场景（场景 3）可用 Levenshtein 编辑距离 + LLM fallback 覆盖
- 阿里云已提供 pgvector，但竞赛阶段非必需

## 后果
- 跨源冲突研判模块使用规则 + LLM 方案
- 预留 pgvector 接口，生产阶段可快速切换
- 名称匹配置信度评分需通过 LLM 推理获得
