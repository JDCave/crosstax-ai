# ADR-003: JSON 文件存储规则

## 状态
已采纳 (2026-10-22)

## 背景
TIN 校验规则需要支持热重载，需选择规则存储方式。

## 决策
采用 JSON 文件存储规则配置，通过内存原子替换实现热重载。

## 否决方案
- **数据库存储规则**：竞赛场景无需持久化查询，文件方案更简单

## 理由
- 热重载实现简单：`engine.load_rules(path)` 原子替换内存字典
- 无需数据库依赖，减少部署复杂度
- 版本绑定通过内容哈希生成，确保审计可溯源
- `threading.Lock` 保证线程安全

## 后果
- 规则文件存放于 `rules/` 目录
- 基准规则：`rules_v1_base.json`
- 增量补丁：`rules_v2_patch.json`（演示热重载用）
