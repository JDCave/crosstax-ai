# ADR-004: 调用第三方 Vision API

## 状态
已采纳 (2026-10-22)

## 背景
CRS 表单需要从 PDF/图片中抽取结构化字段，需要 OCR + 理解能力。

## 决策
调用第三方 Vision API（阿里云神机百炼 Qwen-VL-Max）进行表单字段抽取。

## 否决方案
- **自部署 OCR 模型**：竞赛环境无 GPU 资源，训练成本高

## 理由
- 避免自训练模型，快速获得 OCR 能力
- API 调用成本可控（竞赛演示量级）
- Qwen-VL-Max 支持中英文混合表单，准确率高

## 后果
- 需处理 API 超时（15 秒超时 + 1 次重试）
- 低置信度字段标记为需人工复核
- 降级方案：手动输入模式
