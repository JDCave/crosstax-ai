React 实现说明 · Implementation Notes
  • 整体布局使用 Ant Design Layout 组件：Layout.Header + Layout.Sider + Layout.Content
  • Pipeline 状态使用 Steps 组件，通过 WebSocket Hook 实时更新每一步状态（wait/process/finish）
  • 裁决横幅使用 Alert 组件，type 属性按 verdict 类型切换（success/error/warning）
  • 修复卡片使用 Collapse 组件，默认展开 BLOCKER 级别问题，内嵌 Alert 展示修改建议
  • 冲突证据链使用 Collapse + Progress 组件，展示冲突场景 + 置信度百分比
  • 热重载按钮触发 POST /api/v1/rules/reload，成功后使用 message.success() 全局提示
  • 审计底稿使用 Descriptions 组件，关键字段支持 Typography.Text copyable 一键复制
  • 数据请求使用 TanStack Query（React Query），自动缓存 + 重试 + 乐观更新
  • 状态管理使用 Zustand，轻量无模板代码，全局状态仅保留当前 session + 规则版本
