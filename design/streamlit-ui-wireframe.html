Streamlit 实现说明
  • 使用 st.columns([1, 3]) 实现 sidebar + main 布局比例
  • Pipeline 状态使用 st.status() 组件，每步完成后标记 done
  • 裁决横幅使用 st.success() / st.error() / st.warning()
  • 修复卡片使用 st.expander() + 自定义 CSS 实现红/琥珀色左边框
  • 热重载按钮触发 rule_engine.load_rules(patch_path)，使用 st.spinner() 展示加载状态
  • 审计报告使用 st.download_button() 提供 HTML 文件下载
  • 置信度条使用纯 CSS 实现，无需额外图表库
