# CrossTax AI — 跨境资金结算与全球多币种账户税籍合规智能网关

> CROSS-BORDER SETTLEMENT · TAX RESIDENCY · AI AGENTS

## 1. 方案概述

**CrossTax AI** 以 CRS（共同申报准则）税籍自我证明为切入点，协同完成文书识别、税号与规则校验、跨源身份比对及风险分流，让合规审核从反复补件转向实时诊断。

**定位：** 面向跨境支付机构、出海金融平台与 B2B 结算网络的 Compliance-as-a-Service 能力。

### 核心指标

| 指标 | 现状 | 目标 |
|------|------|------|
| 传统人工往返审核时长 | 3–7 个工作日 | 秒级诊断（自动化初筛与即时反馈） |
| 表单错填率 | >35%（项目背景数据） | 显著降低 |

### 从材料到可审计决策（三步流程）

1. **识别** — CRS 表单与签署信息
2. **校验** — TIN、税籍理由与规则
3. **处置** — 放行、补正或人工复核

## 2. 业务问题与价值

### 合规摩擦，正在变成跨境资金链路的经营成本

**关键节点：** 跨境电商结汇、多币种账户开立、离岸企业收款与跨境 B2B 结算。

#### 三大痛点

| # | 问题 | 详情 | 后果 |
|---|------|------|------|
| 01 | **审核慢，结算被拖住** | CRS 规则理解门槛高，错填率超过 35%；传统人工多轮补件通常耗时 3–7 个工作日 | 资金周转延迟 / 商户开户与结算流失 |
| 02 | **税籍难判，监管风险高** | 境内主体与海外实体多层关联，辖区间税号与税务居民规则不同；漏报、误报可能引发穿透审计与处罚 | 牌照、罚款与声誉风险 |
| 03 | **信息分散，冲突难发现** | 注册资料、护照、离岸账户、海外仓地址和联系方式分属不同系统，人工难以快速交叉核验 | 跨源不一致无法及时闭环 |

#### 目标用户

- 跨境支付与收单机构
- 出海金融平台
- 跨境电商与外贸企业
- B2B 结算网络

#### 预期改善（试点验证）

- 缩短合规等待
- 减少重复补件
- 提升商户完成率
- 让人工审核聚焦高风险例外，并保留可追溯审计底稿

#### 跨境价值

把税籍合规前置到开户与结算流程，降低合规摩擦对资金可用性和商户留存的影响。

## 3. 解决方案：多智能体串联审核

### 核心机制

结构化结果 + 规则证据 + 风险置信度作为共享上下文，驱动连续任务与可解释分流。每一步都把中间结果交给下一步。

### 五步审核流水线

| 步骤 | 名称 | 输入 | 产出 |
|------|------|------|------|
| **01** | 接收材料 | CRS PDF、开户资料 | 原始文件 / 商户 ID |
| **02** | 多模态提取 | 主体、TIN、勾选项、签名与日期 | 带页码坐标的结构化 JSON |
| **03** | 税规推理校验 | TIN 格式 / 校验位；Reason A/B/C | 规则命中、缺陷与依据 |
| **04** | 跨源冲突挖掘 | 比对注册、账户、地址及联系信息 | 冲突项与置信度 |
| **05** | 决策与闭环 | 综合以上结果 | 通知、审计底稿、处置状态（自动放行 / 补正 / 人工升级） |

### 工具层

- **OCR / 文档版面解析** — OCR 置信度与签名字段校验
- **TIN 与辖区规则引擎** — 税号格式与辖区规则校验
- **KYC / CRM / 账户资料连接器** — 跨源数据拉取
- **案件工作台与审计日志** — 全流程可追溯

### 安全分流策略

| 场景 | 处置方式 |
|------|----------|
| 低风险且规则确定 | 自动通过 |
| 可修复错误 | 生成商户补正卡 |
| 冲突或低置信度 | 人工复核并留痕 |

### 审计记录

输入版本、规则版本、字段证据、Agent 结论、人工覆核与最终处置全程关联，确保完整可追溯。

## 4. 交付所需：可信规则数据与金融级运行边界

### 数据来源

- 商户提交的 CRS 自我证明
- KYB / 注册主体资料
- 开户与收款账户信息
- 授权使用的地址、联系方式及海外仓信息
- 经合规确认的 OECD 与辖区 TIN / 税规参考

### 工具与系统

- OCR / 文档解析与签名字段校验
- TIN 规则库和版本管理
- KYC、CRM、账户系统 API
- 身份匹配与案件管理工作台
- 可检索的审计日志

### 部署与治理

- 优先采用机构 VPC / 私有云
- 传输与存储加密、RBAC、数据最小化和留存策略
- 按辖区控制数据访问
- 规则由合规团队审核发布
- 低置信度必须人工复核

### 试点指标

- 审核时长
- 一次通过率
- 补件率
- 人工升级率
